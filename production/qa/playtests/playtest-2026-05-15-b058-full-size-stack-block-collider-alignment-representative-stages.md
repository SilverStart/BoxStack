# B058 전체 크기 스택 블록 콜라이더 정렬 대표 스테이지 수동 점검

- 날짜: 2026-05-15
- 빌드 마커: B058
- 대상: Unity Editor Play Mode
- 세션 유형: Stack-like 2D 시각 방향 대표 스테이지 점검
- 해당 검증 사용자: 수동 플레이

## 목적

B058 기준 Stack-like 2D 시각 방향이 실제 플레이 중에도 자연스럽게 읽히는지 확인한다.

B058은 각 박스가 전체 스택 그라데이션 중 자기 구간만 갖도록 스프라이트를 생성하되, B054의 테두리 없는 블록 상태, B055의 진한 시작색, B056의 불투명 가장자리를 유지한다. B057의 비주얼만 `0.96`으로 줄이는 방식은 틈을 만들었기 때문에, 이번에는 Stack-like 블록의 비주얼과 콜라이더를 모두 전체 `WorldSize`로 맞춰 파묻힘과 틈을 함께 줄이는지 확인한다.

## 확인 범위

- 스테이지: 1, 5, 10, 15, 20
- 블록 색상: 아래 박스가 더 진하고 다음 박스가 더 밝게 이어지는가
- 시작 대비: 첫 박스와 낮은 박스가 배경 최상단처럼 아주 진한 톤에서 출발하는가
- 테두리 제거: 어두운 선이 사라진 상태가 더 깔끔하게 보이는가
- 미세 선 제거: 박스가 쌓일 때 사이사이에 검은 선처럼 보이는 배경색 샘플링이 사라졌는가
- 파묻힘/틈 제거: 위 박스가 아래 박스 상단에 묻히거나 떠 보이지 않고 자연스럽게 맞닿는가
- 물리 감각: Stack-like 콜라이더가 4% 커진 뒤에도 쌓기 감각이 유지되는가
- 블록 내부 명암: 박스마다 같은 그라데이션이 반복되지 않고 전체 스택 흐름의 일부처럼 보이는가
- 접촉부 가시성: 박스가 맞닿는 선과 테두리가 충분히 보이는가
- 배경 대비: 배경 그라데이션 위에서 블록 실루엣이 잘 보이는가
- HUD 가시성: 상단 진행 패널, 스테이지 배지, 되돌리기 버튼이 방해되지 않는가
- 기존 감각: 이동 속도, 낙하 충격, 마찰, 되돌리기 사용성이 이전에 수용한 느낌과 동일한가

## 빠른 준비

1. Unity Editor에서 `SampleScene`을 연다.
2. Play Mode를 시작한다.
3. 화면의 작은 빌드 마커가 `B058`인지 확인한다.
4. 스테이지 선택에서 필요하면 `전체 해금`을 사용해 5, 10, 15, 20스테이지를 테스트한다.

## 판단 질문

- 스택 전체가 하나의 세로 색상 흐름처럼 보이는가?
- 위 박스가 아래 박스 상단에 묻히거나 떠 보이지 않고 맞닿아 보이는가?
- Stack-like 콜라이더가 커졌는데도 쌓기 감각, 마찰, 실패 판정이 어색하지 않은가?
- 박스가 맞닿을 때 사이에 검은 선처럼 보이는 얇은 틈이 사라졌는가?
- 첫 박스가 충분히 진해서 Stack-like 고대비 느낌이 나는가?
- 어두운 테두리 선을 제거한 상태가 더 Stack-like 하고 깔끔하게 보이는가?
- 박스마다 독립적인 그라데이션이 반복되는 느낌은 줄어드는가?
- 테두리 선이 없어도 접촉부와 박스 위치를 읽을 수 있는가?
- 후반 스테이지에서 빠르게 움직일 때 블록 위치와 접촉면을 읽기 쉬운가?
- B048 글래스 UI가 배경/블록 위에서 충분히 고급스럽고 방해되지 않는가?
- 지금 상태를 커밋하고 다음 영역으로 넘어가도 되는가?
