# B020 대표 스테이지 Editor Play 수동 점검

## 세션 정보

- 날짜: 2026-05-13
- 빌드 마커: B020
- 기준 커밋: `b2d99b8 B020 스테이지 선택 해금 버튼 수정`
- 플랫폼: Unity Editor Play Mode
- 입력: 마우스/터치 에뮬레이션
- 세션 유형: 대표 스테이지 수동 감각 점검

## 점검 초점

B020에서 스테이지 선택/전체 해금 동작은 자동 점검과 수동 확인을 통과했다. 이번 점검은 기능 버그보다 실제 플레이 감각에 집중한다.

- Delivery Arcade HUD가 게임 화면처럼 읽히는가
- 스테이지 선택 진입과 테스트용 전체 해금 흐름이 빠른가
- 되돌리기 버튼 위치와 크기가 플레이 중 방해되지 않는가
- B008 물리 튜닝과 B012 좌우 이동 보정이 현재 UI 상태에서도 적절한가
- 후반 스테이지 실패가 플레이어 타이밍 문제로 느껴지는가, 물리 랜덤성으로 느껴지는가

## 현재 기준값

- 박스 마찰력: `8.0`
- 바닥 마찰력: `8.0`
- 안착 후 중력: `1.6`
- 낙하 중 중력: `1.1`
- 낙하 속도 상한: `4.5`
- 스테이지당 되돌리기: `1`
- 클리어 검증 시간: `5.0s`
- 단일 기둥 허용 오차: `0.75`
- 좌우 이동: 화면 중앙에서 시작, 오른쪽으로 먼저 이동, 양 끝 속도 유지, 화면 안쪽으로 범위 제한, 제한된 범위에서도 스테이지 속도감 보정
