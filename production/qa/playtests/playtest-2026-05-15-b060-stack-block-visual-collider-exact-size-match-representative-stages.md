# B060 스택 블록 비주얼-콜라이더 동일 크기 수동 평가

- 날짜: 2026-05-15
- 빌드 마커: B060
- 대상: Unity Editor Play Mode
- 검증 유형: Stack-like 2D 비주얼 영역과 콜라이더 영역 동일 크기 수동 평가
- 해당 검증은 사용자의 수동 플레이로 진행한다.

## 목적

B060 기준 Stack-like 생성형 블록의 보이는 비주얼 영역과 `BoxCollider2D` 영역이 같은 크기로 느껴지는지 확인한다.

B060은 B059의 시각 전용 세로 덮기 값을 제거한다. Stack-like 생성형 블록은 보이는 스프라이트 영역과 콜라이더 영역 모두 같은 전체 `boxVisual.WorldSize`를 사용한다.

## 확인 범위

- 스테이지: 1, 5, 10, 15, 20
- 빌드 마커가 `B060`으로 표시되는가
- Scene/Game 시점에서 비주얼 영역과 콜라이더 영역이 같은 크기로 보이는가
- 위 블록이 아래 블록 안으로 파묻혀 보이지 않는가
- 블록 사이가 떠 보이지 않는가
- 얇은 선이나 틈이 남아 있다면 크기 불일치가 아니라 물리 접촉 간격이나 렌더링 샘플링 문제로 분리해서 봐야 하는가
- 박스 착지, 마찰, 실패 판정, 되돌리기 감각이 이전과 다르게 어색해지지 않았는가

## 빠른 준비

1. Unity Editor에서 `SampleScene`을 연다.
2. Play Mode를 시작한다.
3. 화면의 작은 빌드 마커가 `B060`인지 확인한다.
4. 필요하면 스테이지 선택의 `전체 해금`을 사용해 5, 10, 15, 20스테이지를 테스트한다.
