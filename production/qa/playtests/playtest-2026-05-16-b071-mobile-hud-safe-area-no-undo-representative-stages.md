# B071 모바일 HUD safe-area 및 no-undo 대표 스테이지 수동 점검

## 세션 정보

- 날짜: 2026-05-16
- 빌드 마커: B071
- 기준 커밋: `3103e4c 프로토타입 리소스 중복 유지 정책 기록`
- 플랫폼: Unity Editor Play Mode
- 입력: 마우스/터치 에뮬레이션
- 세션 유형: 모바일 HUD safe-area 및 no-undo 기준 대표 스테이지 점검
- 해당 검증은 사용자의 수동 플레이로 진행한다.

## 목적

B071 기준 상단 HUD가 좁은 모바일 safe-area에서 겹치지 않는지 확인한다.

특히 왼쪽 스테이지 배지와 상단 중앙 진행 패널이 서로 침범하지 않는지, 4-12박스 스테이지에서도 진행 슬롯이 읽히는지, 되돌리기 없는 후반 스테이지가 타이밍 실력으로 받아들여지는지 확인한다.

## 현재 기준

- 런타임 마커: `B071`
- 되돌리기: 없음
- 진행 패널: 상단 중앙, 현재 스테이지 primary/accent 계열 슬롯
- HUD safe-area 처리: 진행 패널 최대 폭을 safe-area 기준으로 제한
- 대표 스테이지: 1, 5, 10, 15, 20
- 목표 박스 수: 4, 6, 8, 10, 12

## 빠른 준비

1. Unity Editor에서 `SampleScene`을 연다.
2. Game view를 세로 모바일 비율로 둔다.
3. Play Mode를 시작한다.
4. 화면의 작은 빌드 마커가 `B071`인지 확인한다.
5. 스테이지 배지를 눌러 스테이지 선택을 열고, 필요하면 개발용 전체 해금을 사용한다.

## HUD 점검 항목

- 상단 스테이지 배지와 중앙 진행 패널이 겹치지 않는가
- 중앙 진행 패널이 너무 좁아져 현재 진행 수를 읽기 어렵지 않은가
- 4, 6, 8, 10, 12칸 진행 슬롯이 모두 한눈에 구분되는가
- 빌드 마커가 HUD 조작이나 진행 패널 가독성을 방해하지 않는가
- 스테이지 선택 overlay와 결과 popup이 safe-area 안에서 답답하거나 잘리지 않는가

## no-undo 플레이 감각 점검 항목

- 실패 원인이 타이밍 실수로 읽히는가
- 후반 스테이지 실패가 물리 흔들림이나 운으로 느껴지지 않는가
- 되돌리기가 없어서 흐름이 단순해졌는가, 아니면 너무 가혹해졌는가
- 5초 클리어 검증 대기가 긴장으로 느껴지는가, 답답함으로 느껴지는가
- 재시도 버튼으로 바로 다시 하고 싶은가
