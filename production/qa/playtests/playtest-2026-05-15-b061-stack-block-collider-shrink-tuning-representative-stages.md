# B061 스택 블록 콜라이더 축소 튜닝 수동 평가

- 날짜: 2026-05-15
- 빌드 마커: B061
- 대상: Unity Editor Play Mode
- 검증 유형: Stack-like 2D 콜라이더 축소값 수동 튜닝 평가
- 해당 검증은 사용자의 수동 플레이로 진행한다.

## 목적

B061 기준 Stack-like 생성형 블록의 콜라이더를 비주얼보다 작게 두었을 때, 블록 사이가 자연스럽게 붙어 보이는지 확인한다.

B061은 보이는 스프라이트 영역을 전체 `boxVisual.WorldSize`로 유지하고, `BoxCollider2D.size`만 `boxVisual.WorldSize * 0.96f`로 줄인다. 이 값은 확정값이 아니라 수동 플레이 중 조정할 시작점이다.

## 확인 범위

- 스테이지: 1, 5, 10, 15, 20
- 빌드 마커가 `B061`로 표시되는가
- 블록 사이가 떠 보이지 않는가
- 위 블록이 아래 블록 안으로 과하게 파묻혀 보이지 않는가
- 얇은 선이나 틈이 이전보다 줄었는가
- 박스 착지, 마찰, 실패 판정, 되돌리기 감각이 이전과 다르게 어색해지지 않았는가
- `0.96f`보다 크거나 작은 값으로 조정할 필요가 있는가

## 빠른 준비

1. Unity Editor에서 `SampleScene`을 연다.
2. Play Mode를 시작한다.
3. 화면의 작은 빌드 마커가 `B061`인지 확인한다.
4. 필요하면 [BoxStackPrototype.cs](C:/unity/BoxStack/Assets/Scripts/Prototype/BoxStackPrototype.cs)의 `boxVisual.WorldSize * 0.96f` 값을 조정한다.
