# B059 스택 블록 시각 틈 가림 대표 스테이지 수동 평가

- 날짜: 2026-05-15
- 빌드 마커: B059
- 대상: Unity Editor Play Mode
- 검증 유형: Stack-like 2D 시각 틈 가림 수동 평가
- 해당 검증은 사용자의 수동 플레이로 진행한다.

## 목적

B059 기준 Stack-like 블록이 쌓일 때 박스 사이에 얇은 검은 선이나 배경색 틈이 보이는지 확인한다.

B059는 전역 Physics2D 설정을 바꾸지 않고, Stack-like 생성형 블록의 콜라이더는 전체 `WorldSize`로 유지한다. 대신 보이는 스프라이트만 세로로 `0.024` 월드 유닛 더 크게 그려 Unity 2D 접촉 간격 때문에 생기는 시각적 틈을 가리는지 테스트한다.

## 확인 범위

- 스테이지: 1, 5, 10, 15, 20
- 빌드 마커가 `B059`로 표시되는가
- 블록 사이에 얇은 검은 선이나 배경색 틈이 사라졌는가
- 위 블록이 아래 블록 안으로 과하게 파묻혀 보이지 않는가
- 블록 사이에 반대로 공간이 떠 보이지 않는가
- 박스 착지, 마찰, 실패 판정, 되돌리기 감각이 이전과 다르게 어색해지지 않았는가
- 스택 전체 색상 흐름이 아래는 진하고 위는 밝게 자연스럽게 이어지는가
- HUD와 진행 슬롯이 블록 확인을 방해하지 않는가

## 빠른 준비

1. Unity Editor에서 `SampleScene`을 연다.
2. Play Mode를 시작한다.
3. 화면의 작은 빌드 마커가 `B059`인지 확인한다.
4. 필요하면 스테이지 선택의 `전체 해금`을 사용해 5, 10, 15, 20스테이지를 테스트한다.
