# HUD Variants

Generated: 2026-05-04

These are prototype mockups for choosing the next BoxStack HUD direction. They are not implemented UI.

## Variants

1. `hud-variant-01-toss-minimal.png` - quiet app-like top bar with compact box count, progress, and pause affordance.
2. `hud-variant-02-delivery-tracker.png` - delivery-status style header plus a right-side vertical progress rail.
3. `hud-variant-03-casual-game.png` - more playful game HUD with score panel, combo badge, and center feedback toast.
4. `hud-variant-04-no-top-hud.png` - removes most top UI, keeps progress near the play area/side rail.

## Recommendation

Start with 01 or 04 if Toss app-in-app fit is the priority. Use 02 if the parcel/delivery metaphor should be more explicit. Use 03 only if playtests need stronger arcade feedback.
