# BoxStack Stack-like 2D 디자인 가이드

마지막 갱신: 2026-05-15

## 목적

현재 BoxStack 프로토타입의 배송/택배 앱 느낌을 걷어내고, Ketchapp `Stack`에 가까운 미니멀 추상 블록 게임 느낌으로 전환하기 위한 기준 문서입니다. 원본은 3D 아이소메트릭 게임이지만, BoxStack은 2D 물리 스택 게임이므로 완전한 3D 모사보다 2D에서 읽히는 단순한 형태와 색 변화에 집중합니다.

## 시각 원칙

1. 플레이 화면의 주인공은 장식이 아니라 쌓이는 블록입니다.
2. 배경은 색 분위기만 만들고, 중앙 플레이 영역을 방해하지 않습니다.
3. UI는 최소한의 정보만 보여주며, 버튼과 팝업도 반투명하고 가볍게 유지합니다.
4. 성공/실패 피드백은 큰 이미지보다 짧은 텍스트, 하이라이트, 색 변화로 전달합니다.
5. 블록은 박스/택배 패키지가 아니라 추상적인 컬러 블록으로 보이게 합니다.

## 2D 변환 규칙

- 원본의 아이소메트릭 깊이감은 이번 프로토타입에서는 과감히 줄이고, 블록을 단순한 단색 직사각형 실루엣과 얇은 진한 테두리로 읽히게 합니다.
- 블록 실루엣은 물리 판정이 읽히도록 직사각형에 가깝게 유지합니다.
- 텍스처 디테일은 제거하고, 색상 변화와 얇은 테두리만으로 게임성을 강조합니다.
- 블록은 아래쪽에서 위쪽으로 쌓일수록 같은 계열 안에서 점점 진해져야 하며, 충돌면과 가장자리는 진한 테두리로 읽혀야 합니다.
- 배경은 세로 그라데이션 중심으로 사용하고, 실제 공간/창고/소품 이미지는 사용하지 않습니다.

## 팔레트 방향

- 배경: 스테이지별로 같은 색 계열 안에서 하단/중간/상단 색이 이어지는 부드러운 세로 그라데이션.
- 블록: 현재 스테이지 팔레트 안에서 기본색에서 강조색으로 단방향 이동하며, 아래쪽은 연하고 위쪽은 진하게 보이는 색.
- 진행 슬롯: 현재 스테이지의 보조 강조색을 사용해 배경과 분리하되 전체 색 계열에서 벗어나지 않습니다.
- 실패: 붉은색 한 가지로만 의미를 부여하고, 텍스트도 함께 사용합니다.
- UI: 흰색 텍스트와 낮은 불투명도의 어두운 패널.

## 스테이지 팔레트 규칙

- 팔레트는 청록/블루, 보라/핑크, 코랄/선셋, 민트/틸, 인디고/시안, 라벤더/블루 계열을 순환합니다.
- 한 스테이지 안에서는 배경, 블록, 바닥, HUD 강조색이 같은 계열에서 파생되어야 합니다.
- 블록은 매번 완전히 다른 색으로 바뀌기보다 같은 계열 안에서 쌓인 순서에 따라 밝기와 색상 위치가 부드럽게 깊어져야 합니다.
- UI 패널은 팔레트 색을 직접 넓게 칠하지 않고, 어두운 반투명 패널에 강조색만 얹어 사용합니다.

## UI 방향

- 플레이 중 HUD는 `STAGE`, 진행 슬롯, 되돌리기 버튼, 빌드 마커 정도만 유지합니다.
- 배송, 적재, 루트 같은 택배 세계관 문구는 사용하지 않습니다.
- 결과 팝업은 `CLEAR`, `MISS`, `클리어`, `실패`처럼 짧은 게임 문구를 사용합니다.
- 스테이지 선택은 기능 확인용으로 유지하되, 화면 스타일은 플레이 HUD와 같은 반투명 어두운 패널로 맞춥니다.

## 현재 적용 범위

- 런타임 마커: B039
- `BoxStackPrototype`은 추상 블록 모드를 켜고, 현재 스테이지 팔레트에 맞춰 배경/바닥/블록 색을 갱신합니다.
- `BoxStackPrototypeAssetLoader`는 런타임에서 블록, 팔레트 기반 바닥, 팔레트 기반 그라데이션 배경 스프라이트를 생성합니다.
- 기존 택배 PNG 리소스는 삭제하지 않고 보존하지만, B039 기본 런타임에서는 사용하지 않습니다.
- B033에서는 `Stack` 레퍼런스에 더 가깝게 뒷 배경 방향을 조정합니다. 배경 하단은 연하고 밝은 색으로, 중간은 선명한 연결색으로, 상단은 진하고 어두운 색으로 둡니다.
- B034에서는 생성된 `16x256` 배경 그라데이션 스프라이트를 화면에 맞출 때 X/Y를 독립적으로 스케일해 전체 세로 그라데이션이 Game View에 보이도록 합니다.
- B035에서는 수동 테스트로 바꿨던 Stage 1 AquaBlue 배경 hue 값을 원래 의도한 `0.47 / 0.52 / 0.61` 흐름으로 되돌립니다.
- B036에서는 B034 표시 버그 때문에 과하게 올렸던 배경 명암 대비를 완화합니다. 하단은 밝고 상단은 어두운 `Stack`식 방향은 유지하되, 상단을 거의 검정에 가깝게 두지 않아 블록보다 배경이 튀지 않도록 합니다.
- B037에서는 추상 블록의 윗면/측면 명암을 제거하고 단색 직사각형 실루엣으로 단순화합니다. 블록 색상은 스테이지 안에서 아래쪽 연한 색에서 위쪽 진한 색으로 단방향 진행합니다.
- B038에서는 단색 블록이 배경에 묻히지 않도록, 블록 겉 테두리 픽셀만 진한 값으로 칠해 같은 틴트 안에서 더 어두운 윤곽이 보이게 합니다.
- B039에서는 이동 중 박스와 착지 후 박스가 같은 틴트를 사용하게 해, 착지 순간 색이 더 진해지는 시각 변화를 제거합니다.
- UI 문구와 색상은 배송 테마에서 미니멀 스택 테마로 전환했고, 진행 슬롯/버튼/결과 강조색은 스테이지 팔레트를 따릅니다.

## 다음 확인 포인트

- 추상 블록이 물리 충돌 위치를 충분히 명확하게 보여주는지 확인합니다.
- 배경 그라데이션이 블록 색과 겹쳐 가독성을 해치지 않는지 확인합니다.
- 상단 HUD가 너무 앱처럼 보이지 않는지 확인합니다.
- 폰트가 미니멀 블록 게임 톤에 맞는지, 아니면 더 얇고 간결한 폰트가 필요한지 확인합니다.
